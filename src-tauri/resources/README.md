# ADB Platform-Tools

This directory will contain bundled ADB binaries for each platform.
They will be downloaded and placed here in Phase 2.

Expected structure:
```
resources/
├── platform-tools-linux/
│   └── adb
├── platform-tools-windows/
│   └── adb.exe
└── platform-tools-macos/
    └── adb
```

ADB platform-tools are licensed under Apache 2.0 and can be freely redistributed.
Download from: https://developer.android.com/tools/releases/platform-tools
